# VENOM LOG Website v2

Render Web Service. Build: `npm install`; Start: `npm start`.

Required environment variables: `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `DISCORD_REDIRECT_URI`, `SESSION_SECRET`, `DATABASE_URL`, `INTERNAL_API_SECRET`, `BOT_API_URL`, `NODE_ENV=production`.

Set the exact OAuth redirect URL to `https://YOUR-WEBSITE.onrender.com/auth/discord/callback`. Keep all secrets private.
